## 🚀 Встановлення

### Передумови
- Веб-браузер (Chrome, Firefox, Safari, Edge)
- Локальний HTTP-сервер (рекомендується)

### Кроки встановлення

1. **Клонуйте репозиторій**
   ```bash
   git clone https://github.com/your-repo/Ecobazar.git
   cd Ecobazar-main
   ```

2. **Запустіть локальний сервер**
   
   Якщо у вас встановлений Python:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # або Python 2
   python -m SimpleHTTPServer 8000
   ```
   
   Якщо у вас встановлений Node.js:
   ```bash
   npx http-server
   ```

3. **Відкрийте у браузері**
   ```
   http://localhost:8000
   ```

## 📦 Структура даних

### Товари (products.json)
```json
{
  "id": 1,
  "name": "Зелене яблуко",
  "price": 14.99,
  "oldPrice": 20.99,
  "image": "img/products/Apple.webp",
  "rating": 5,
  "sale": true,
  "category": "Фрукти",
  "tags": ["солодке", "свіже"]
}
```

### Сторінки товарів
- **id** - унікальний ідентифікатор
- **name** - назва товару
- **price** - поточна ціна
- **oldPrice** - стара ціна (для знижок)
- **image** - шлях до зображення
- **rating** - рейтинг від 1 до 5
- **sale** - наявність акції
- **category** - категорія товару
- **tags** - мітки для пошуку

### Блог (blog.json)
Структура містить дату, автора, категорію та вміст статей.
